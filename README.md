# Kingdom 3514 – Weekly Activity Dashboard

**View it:** https://rizkyekoputra.github.io/rok-3514-dashboard/

Weekly barbarian fort and tech donation activity for the [14-X] alliance in Rise of Kingdoms
kingdom 3514. Minimum per week: **70 forts** and **50,000 tech**.

- Search a player to see their forts and tech per week, offense status and unpaid fines.
- Link straight to a player with `#p=<name>`, e.g. `…/rok-3514-dashboard/#p=wowsih`.
- The table lists everyone for the selected week; click a row to open that player.

Fort counts are per player; a fort destroyed in a rally counts for every participant.
Weeks where only part of the ranking was captured are marked "partial data".

This page is generated each week. Please don't edit it by hand.
